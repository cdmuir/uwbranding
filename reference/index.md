# Package index

## Brand Colors

Named color vectors and lookup helpers for UW–Madison brand colors.

- [`uw_colors`](https://cdmuir.github.io/uwbranding/reference/uw_colors.md)
  : UW–Madison brand colors
- [`uw_color()`](https://cdmuir.github.io/uwbranding/reference/uw_color.md)
  : Look up UW–Madison brand colors by name

## Color Palettes

Ordered palettes for light and dark backgrounds, and their palette
functions.

- [`uw_palette_discrete`](https://cdmuir.github.io/uwbranding/reference/uw_palette_discrete.md)
  : UW–Madison discrete palette for light backgrounds
- [`uw_palette_dark`](https://cdmuir.github.io/uwbranding/reference/uw_palette_dark.md)
  : UW–Madison discrete palette for dark backgrounds
- [`uw_pal()`](https://cdmuir.github.io/uwbranding/reference/uw_pal.md)
  : UW brand discrete palette function for light backgrounds
- [`uw_pal_dark()`](https://cdmuir.github.io/uwbranding/reference/uw_pal_dark.md)
  : UW brand discrete palette function for dark backgrounds
