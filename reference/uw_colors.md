# UW–Madison brand colors

A named character vector of hex codes for all official UW–Madison brand
colors. Primary and secondary digital colors are taken directly from
<https://brand.wisc.edu/visual-identity/colors/>. Accent colors are
approximate hex conversions from the published print CMYK values.

## Usage

``` r
uw_colors
```

## Format

A named character vector with eight elements:

- badger_red:

  `#C5050C` — primary brand color

- white:

  `#FFFFFF`

- dark_red:

  `#9B0000` — secondary digital

- light_gray:

  `#E1E5E7` — secondary digital

- black:

  `#121212` — secondary digital

- yellow:

  `#FFBF00` — print accent (CMYK 0, 25, 100, 0)

- gray_blue:

  `#6B9999` — print accent (CMYK 30, 0, 0, 40)

- blue:

  `#386666` — print accent (CMYK 45, 0, 0, 60)
